Política de Privacidade

Escritório JS · JS Mentoria · Atualizada em 13 de outubro de 2026

O Escritório JS é a ferramenta interna de organização da JS Mentoria (Jéssica Sandi), usada apenas pela equipe da empresa para gerenciar tarefas, reuniões e eventos de trabalho.

Quais dados do Google acessamos

Quando uma integrante da equipe conecta a própria conta Google, o Escritório JS solicita acesso a:

  • Google Tasks — para criar, atualizar e concluir as tarefas que ela registrou no Escritório, e para identificar quando uma dessas tarefas foi concluída no Google.
  • Google Agenda (eventos) — para criar, atualizar e remover as reuniões e eventos que ela registrou no Escritório.
  • Endereço de e-mail — apenas para mostrar qual conta está conectada.

Como usamos esses dados

Os dados são usados exclusivamente para manter sincronizados os itens do Escritório com a agenda e as tarefas da própria pessoa. Não lemos, alteramos ou apagamos tarefas e eventos que não foram criados pelo Escritório JS.

Armazenamento e compartilhamento

As credenciais de acesso ficam armazenadas de forma protegida no servidor, nunca no navegador. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade ou treinamento de modelos.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como desconectar

A qualquer momento, em Configurações → Desconectar no Escritório, ou em myaccount.google.com/permissions. Ao desconectar, as credenciais são apagadas do servidor.
